### 参数变化 → 上层空间 → Majorana 行为：研究计划草案

目标：系统理解

- 不同 $(a,b,c,d)$ 选择（满足 YBE 的 R 家族）
- 如何通过 1D/2D 映射改变上层的拓扑/范畴结构（相位、spin 结构、mapping class 表示）
- 最终在低能 Majorana/任意子自由度上体现为哪些可观测行为：零模结构、有效耦合、绕行相位等。

下面按“三层映射”给出一个可执行的计划：

 

#### I. R → BdG/Majorana：构造与参数扫描

1. **明确 R 参数族与约束**
	- 选定一族满足 YBE 的 $R(a,b,c,d)$（可从 R_to_Kitaev 中已有约束出发），给出参数子空间（如固定 $a,d$，扫描 $(b,c)$）。
	- 记录物理上有意义的子族（幺正、实系数、无四费米或可控四费米）。

2. **R → 1D Kitaev 链 / 2D BdG 的映射实现**
	- 在代码中实现从 $(a,b,c,d)$ 到 $(t,\Delta,\mu)$ 的映射（1D 情形已推导完备）。
	- 在 2D 方格/蜂窝格上，为每种键方向指定一组 $(a,b,c,d)$，构造带 Z2 链变量 $u_{ij}$ 的 BdG 哈密顿 $H[c,u]$。

3. **粗相图：bulk 能隙与拓扑不变量**
	- 扫描选定参数平面，数值计算：
	  - bulk 能隙 $\Delta_\text{gap}(a,b,c,d)$；
	  - Chern 数或其它拓扑不变量（已有 verify 脚本基础上扩展到 2D）。
	- 标出：trivial 区、Ising‑like 区、其它候选拓扑相区（若出现）。

 

#### II. 固定相区：上层空间与 mapping class 行为

在一个具体的拓扑相区（优先选 Ising‑like 区）中，固定若干代表性参数点，研究其“上层空间结构”和 mapping class 表示。

4. **几何与格点设置**
	- 选择简单几何：
	  - (a) 有边界的线网（多条 Kitaev 链相连，边界处有 Majorana 端点），或
	  - (b) 小尺寸环面（周期边界），允许引入 Z2 通量/自旋结构。
	- 为该几何构造对应的 BdG/Majorana 哈密顿矩阵 $\mathcal H$（含 Z2 背景 $\{u_{ij}\}$）。

5. **低能 Majorana/任意子 Hilbert 空间**
	- 对给定 $(a,b,c,d)$ 与 Z2 配置 $u$：
	  - 数值对角化 $\mathcal H$，提取零模及近零能本征态；
	  - 将低能 Hilbert 空间写为 Majorana 模式 $\{\gamma_a\}$ 的有效哈密顿
		 $$H_{\text{eff}} = \frac i2\sum_{a<b}A_{ab}\gamma_a\gamma_b,$$
		  记录 $A_{ab}(a,b,c,d)$，用以表征有效耦合结构。

6. **mapping class / Dehn‑like 操作的格点实现**
	- 选取若干代表性的闭曲线/操作 $\gamma$：
	  - 线网：绕某个缺陷/端点的闭路；
	  - 环面：a‑cycle, b‑cycle 等。
	- 用局域 R 与 Z2 操作构造相应的幺正算符 $U_\gamma$（例如沿 $\gamma$ 的有序乘积）。
	- 在低能子空间上投影：
	  $$\rho(T_\gamma) = P_{\text{zero}}\,U_\gamma\,P_{\text{zero}},$$
	  得到 mapping class 元素（Dehn 扭转/绕行）的有效作用矩阵。

7. **与已知 TQFT/MTC 的对接（从微观到范畴）**
	- 对 Ising‑like 相区：
	  - 对比零模数目、缠绕相位、本征值结构，识别粒子类型 $1,\psi,\sigma$；
	  - 用已知的 Ising MTC 的 F,R,S,T 数据解释 $\rho(T_\gamma)$ 与有效耦合 $A_{ab}$ 的结构（在合适基底下同构）。
	- 若发现非 Ising 型相区，再尝试匹配其它已知 MTC 或 trivial/two‑copy 结构。

 

#### III. 参数变化 → 上层结构变化 → Majorana 行为变化

在上述工具基础上，研究沿参数路径的“行为流形”。

8. **选定参数路径**
	- 在已知拓扑相区内选取一条或多条连续路径（例如：固定 $a,d$，从 $b=c$ 变到 $b=-c$；或逐渐打开 $d$）。
	- 避免穿越 bulk gap 关闭的相界（若需也可专门研究相变点）。

9. **沿路径追踪 bulk 与零模结构**
	- 在路径若干采样点上重复步骤 3–6：
	  - 记录 bulk gap 与拓扑不变量（验证仍在同一相区）；
	  - 提取 $H_{\text{eff}}$ 的 $A_{ab}$，看哪些 Majorana 耦合随参数出现/增强/消失；
	  - 对比 $\rho(T_\gamma)$ 的本征值/本征矢如何连续变化。

10. **几何/范畴解释：从映射类到耦合的字典**
	 - 将数值结果与范畴/几何视角对应起来：
		- 哪些耦合的出现对应某条曲线 $\gamma$ 的 Dehn 扭转从“平庸”变为“非平庸”（绕行相位改变）；
		- 哪些耦合的消失对应某些 mapping class 元素在拓扑子空间中变成单位元；
		- 在不同 Z2 背景（不同 Wilson 环/自旋结构）下，同一条 $\gamma$ 的作用如何不同，反映 Majorana 对 spin 结构/规范场的敏感方式。

11. **整理和抽象：从具体数值到普适规律**
	 - 概括在给定相区内：“参数变化 → 上层空间变换的哪些特征 → Majorana 有效耦合与粒子行为的哪些特征”；
	 - 尝试提炼：
		- 哪些现象是该 TQFT/MTC 的**普适特征**（与微观细节无关），
		- 哪些细节依赖于具体的 R 族（YBE 解族的“微观标签”）。

这一计划完成后，可以实现：

- 在给定 YBE 解族 $R(a,b,c,d)$ 内，通过拓扑/范畴语言（mapping class group, Dehn twist, spin 结构）来系统理解 Majorana 粒子的行为与有效耦合如何随参数流动；
- 为后续“从 R 的代数结构反推可能的上层空间与 TQFT”提供具体数值和范畴上的依据。
