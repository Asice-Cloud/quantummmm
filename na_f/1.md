# $E_1=0$ 时 Riccati ODE 的正确分量分析

> 基于正确的物理 $A,B,C,D$（`report.md` §3.4）。
> 纠正了旧 qbq.md 中将对角生成元参数 $(t_2,t_3,E_1)$ 错填进非对角块 $B,C$ 的错误。

---

## 一、$E_1=0$ 时的 $A,B,C,D$

$$A = D = \frac{|t_3|}{2}\mathbf{i} + \frac{|t_2|}{2}\mathbf{j}$$

$$B = \frac{|t_1|}{2} + \frac{E_d}{2}\mathbf{k},\qquad C = -\frac{|t_1|}{2} + \frac{E_d}{2}\mathbf{k}$$

$A,D$ 在 $\operatorname{span}\{\mathbf{i},\mathbf{j}\}$ 中（纯虚，来自对角生成元 $\Sigma_{12},\Sigma_{24},\Sigma_{34}$）。

$B,C$ 在 $\operatorname{span}\{1,\mathbf{k}\}$ 中（标量 + $\mathbf{k}$，来自非对角生成元 $\Sigma_{15},\Sigma_{45}$）。

Riccati ODE：
$$\dot q = C + [A,q] - qBq,\qquad q(0)=0$$

---

## 二、$q$ 的分量展开

$q = q_0 + q_1\mathbf{i} + q_2\mathbf{j} + q_3\mathbf{k}$（一般四元数，含标量部分）。

### 2.1 $C$ 的分量

$$C_0 = -\frac{|t_1|}{2},\quad C_1=0,\quad C_2=0,\quad C_3 = \frac{E_d}{2}$$

### 2.2 $[A,q]$ 的分量

$A = A_1\mathbf{i} + A_2\mathbf{j}$，其中 $A_1 = |t_3|/2$，$A_2 = |t_2|/2$。

$[A,q]$ 对标量分量为零（纯虚四元数与任意四元数的对易子无标量部分）。

矢量部分：
$$[A,q] = 2(A_2q_3 - A_3q_2)\mathbf{i} + 2(A_3q_1 - A_1q_3)\mathbf{j} + 2(A_1q_2 - A_2q_1)\mathbf{k}$$

由于 $A_3=0$：
$$[A,q] = |t_2|q_3\,\mathbf{i} - |t_3|q_3\,\mathbf{j} + (|t_3|q_2 - |t_2|q_1)\,\mathbf{k}$$

### 2.3 $qBq$ 的分量

$B = b_0 + b_3\mathbf{k}$，$b_0 = |t_1|/2$，$b_3 = E_d/2$。

四元数乘法展开得：

$$\boxed{\begin{aligned}
(qBq)_0 &= b_0(q_0^2 - q_1^2 - q_2^2 - q_3^2) - 2b_3 q_0q_3 \\
(qBq)_1 &= 2b_0 q_0q_1 - 2b_3 q_1q_3 \\
(qBq)_2 &= 2b_0 q_0q_2 - 2b_3 q_2q_3 \\
(qBq)_3 &= 2b_0 q_0q_3 + b_3(q_0^2 + q_1^2 + q_2^2 - q_3^2)
\end{aligned}}$$

---

## 三、完整分量 ODE（$E_1=0$）

$$\boxed{\begin{aligned}
\dot q_0 &= -\frac{|t_1|}{2} - \frac{|t_1|}{2}(q_0^2 - q_1^2 - q_2^2 - q_3^2) + E_d q_0q_3 \\[4pt]
\dot q_1 &= |t_2|q_3 - |t_1|q_0q_1 + E_d q_1q_3 \\[4pt]
\dot q_2 &= -|t_3|q_3 - |t_1|q_0q_2 + E_d q_2q_3 \\[4pt]
\dot q_3 &= \frac{E_d}{2} + |t_3|q_2 - |t_2|q_1 - |t_1|q_0q_3 - \frac{E_d}{2}(q_0^2+q_1^2+q_2^2-q_3^2)
\end{aligned}}$$

初始：$q_0(0)=q_1(0)=q_2(0)=q_3(0)=0$。

---

## 四、$t=0$ 时的瞬时行为

$$\dot q_0(0) = -\frac{|t_1|}{2},\quad \dot q_1(0) = 0,\quad \dot q_2(0) = 0,\quad \dot q_3(0) = \frac{E_d}{2}$$

**关键结论**：只要 $t_1 \neq 0$ 或 $E_d \neq 0$，$q_0$ 和 $q_3$ 在 $t=0^+$ 立刻非零。**$q_3 \equiv 0$ 不是解。**

$t_1 = E_d = 0$（纯 MZM 极限）时：$\dot q_0 = \dot q_3 = 0$，$q_0 \equiv q_3 \equiv 0$ 是解，此时 $q$ 退化为纯虚四元数。这是一致性检验——纯 MZM 极限下旧结论恢复。

---

## 五、$\sigma_z$ 的保护机制不在 $q_3$ 层面

$q_3(t)$ 逐点非零（一般情况），但物理上 $E_1=0$ 时 Bloch 矢量 $v_y=0$（数值验证确认）。

保护不在 $q$ 的逐点值，而在 **$K_{\text{eff}}$ 的时间积分层面**。

MZM 感受到的有效生成元：

$$K_{\text{eff}} = A + Bq$$

其 $\mathbf{k}$ 分量（即 $\sigma_z$ 分量）来自 $Bq$：

$$(K_{\text{eff}})_k = (Bq)_k = \frac{|t_1|}{2}q_3 + \frac{E_d}{2}q_0$$

这个量**逐点非零**。保护来自三步门控的时间积分：

$$\int_0^{3\tau} (K_{\text{eff}})_k \, dt = 0$$

### 为什么积分为零？

$q_0$ 和 $q_3$ 的演化由 $[A,q]$（$|t_2|,|t_3|$ 的脉冲驱动）和 $qBq$（$|t_1|,E_d$ 的脉冲驱动）共同决定。

三步协议的 $f_m, f_p$ 脉冲对称性使得 $(K_{\text{eff}})_k$ 在 Step 1 的正累积被 Step 3 的负累积抵消，Step 2 自身内部也因 $\int f_m = \int f_p$ 而抵消。

这是一个**全局积分约束**——由脉冲对称性保证，不要求 $q_3(t)$ 逐点为零。

## 六、$K$ 与 $H_{EM}$ 的关系

三个层次：

| 对象 | 作用空间 | 维数 | 关系 |
|------|---------|------|------|
| $H_{EM}$ | 5 Majorana 的 Fock 空间 | 32 维 | 物理哈密顿量 |
| $K$ | 旋量空间（$2\times2$ 四元数 = $\mathbb{H}^2$） | 4 复维 | 旋量表示下的生成元 |
| $K_{\text{eff}} = A + Bq$ | MZM 子空间（通过 $q$ 约化后） | 1 个四元数 | ancilla 消去后的有效生成元 |

$K$ 和 $H_{EM}$ 的系数完全对应——同样的 $E_1, |t_2|, |t_1|, |t_3|, E_d$ 乘以不同表示下的生成元。
Riccati 约化后 $K_{\text{eff}}$ 的 $\mathbf{k}$（$\sigma_z$）分量**不等于**裸 $H_{EM}$ 的 $\sigma_z$ 系数：

| | 裸 $H_{EM}$ 的 $\sigma_z$ | $K_{\text{eff}}$ 的 $\mathbf{k}$ 分量 |
|---|---|---|
| $E_1=0$ 时 | **严格为零** | **非零**（ancilla 介导的诱导项） |
| 来源 | $E_1\gamma_1\gamma_2$ | $Bq$（$|t_1|q_3 + E_d q_0$） |

ancilla 消除不是免费的——有效理论里会出现原始哈密顿量中没有的项，类似于 Born-Oppenheimer
近似中的几何势能。三步脉冲的巧妙之处在于这些诱导项在时间积分后恰好正负相消。

---

## 七、$\mathbf{k}$ 分量的对应关系

$$i\mathbf{k} \leftrightarrow i\gamma_1\gamma_2 \leftrightarrow \sigma_z$$

Riccati 分析中的 "$K_{\text{eff}}$ 的 $\mathbf{k}$ 分量" 就是作用在 MZM 子空间上的
$\sigma_z$ 分量，对应 $\gamma_1\gamma_2$ 杂化方向。$E_1=0$ 时被保护的就是这个方向。

注意区分：$q$ 的 $\mathbf{k}$ 分量（$q_3$）来自 $E_d$ 驱动（通过 $C$），不等于物理上的
$\sigma_z$ 杂化——物理 $\sigma_z$ 效应取决于 $K_{\text{eff}}$ 的积分，不是 $q$ 的瞬时值。

## 八、$qBq$ 非线性项的物理意义

### 8.1 追溯来源

分块运动方程：

$$\dot X = AX + BZ,\qquad \dot Z = CX + DZ$$

定义 $q = ZX^{-1}$，求导：

$$\dot q = \dot Z X^{-1} - ZX^{-1}\dot X X^{-1} = C + Dq - qA - q(BZX^{-1}) = C + Dq - qA - qBq$$

### 8.2 物理图像

$qBq$ 是一个**二次反馈闭环**：

$$q \;\cdot\; B \;\cdot\; q$$

- 第一个 $q$：ancilla 有多少振幅可以往回灌（来自 $Z$）
- $B$：回灌的耦合常数（$t_1, E_d$）
- 第二个 $q$：回灌后 MZM 变了，ancilla 的相对比值 $q$ 跟着变

完整回路：ancilla 泄漏 → ancilla 演化 → ancilla 回灌 MZM → MZM 被改变 → ancilla 的相对比重 $q$ 随之调整 → 再影响下一次回灌。

### 8.3 与其他项对比

| 项 | 物理 | 对 $q$ 的依赖 |
|----|------|-------------|
| $C$ | ancilla 的"真空注入"（$t_1, E_d$ 直接驱动） | 零次 |
| $Dq - qA$ | ancilla 和 MZM 各自的旋转对 $q$ 的拉动 | 线性 |
| $qBq$ | ancilla 回灌的完整反馈闭环 | **二次** |

## 九、$E_1 \neq 0$ 的机制：打开线性通道，不是放大

### 9.1 $E_1$ 做了什么

$E_1 \neq 0$ 时 $A \neq D$：

$$Dq - qA = [A,q] - E_1\,\mathbf{i}\,q$$

$\mathbf{i}q$ 的四元数乘法效果是**分量对转**：

$$-\mathbf{i}\,(q_0 + q_1\mathbf{i} + q_2\mathbf{j} + q_3\mathbf{k}) = -q_0\mathbf{i} + q_1 + q_3\mathbf{j} - q_2\mathbf{k}$$

关键通道：$q_2 \leftrightarrow q_3$（即 $\sigma_y \leftrightarrow \sigma_z$）。

### 9.2 $qBq$ 不是放大 $E_1$

$qBq$ 放大的是**已经被 $E_1$ 改变了**的 $q$ 轨迹。$qBq$ 本身不含 $E_1$——$B = |t_1|/2 + E_d\mathbf{k}/2$。
$E_1$ 的作用是**打开通道**，$qBq$ 是在新通道内产生非线性效应。

### 9.3 为什么 $E_1$ 比 $t_1$ 影响更大

| | $E_1$ | $t_1$ |
|---|---|---|
| 作用方式 | 改变方程**结构**（线性部分类型变化） | 在已有结构内**驱动**（源项和耦合系数） |
| 性质 | 定性（对称性破缺） | 定量 |
| 后果 | 改变轨迹的拓扑类型 | 在已有类型内推拉 |

$E_1=0$：$A=D$，$[A,q]$ 是纯旋转 → $\sigma_z$ 通道关闭（积分抵消）
$E_1\neq 0$：$A\neq D$，$Dq - qA$ 混合旋转和拉伸 → $\sigma_z$ 通道打开

## 十一、$E_1 \neq 0$ 时 ODE 的结构变化（修正版）

> **纠错**：此前版本错误地在 $\dot q_2, \dot q_3$ 中引入了 $E_1$ 线性项。
> 正确推导（sympy 验证）显示 $E_1$ **仅直接耦合** $q_0 \leftrightarrow q_1$，
> 对 $q_2, q_3$ 的作用完全通过 $qBq$ 非线性反馈。

### 11.1 完整分量 ODE（$E_1 \neq 0$，正确版）

记 $b_0 = |t_1|/2$，$b_3 = E_d/2$。$Dq - qA$ 的精确分量（sympy 验证）：

$$Dq - qA: \quad (0)=E_1 q_1,\; (\mathbf{i})=-E_1 q_0 + |t_2| q_3,\; (\mathbf{j})=-|t_3| q_3,\; (\mathbf{k})=|t_3| q_2 - |t_2| q_1$$

$$\boxed{\begin{aligned}
\dot q_0 &= -\frac{|t_1|}{2} + \color{red}{E_1 q_1} - b_0(q_0^2 - q_1^2 - q_2^2 - q_3^2) + 2b_3 q_0 q_3 \\[4pt]
\dot q_1 &= |t_2|q_3 \color{red}{- E_1 q_0} - 2b_0 q_0 q_1 + 2b_3 q_1 q_3 \\[4pt]
\dot q_2 &= -|t_3|q_3 - 2b_0 q_0 q_2 + 2b_3 q_2 q_3 \quad \text{（无 $E_1$ 直接项）} \\[4pt]
\dot q_3 &= \frac{E_d}{2} + |t_3|q_2 - |t_2|q_1 - 2b_0 q_0 q_3 - b_3(q_0^2 + q_1^2 + q_2^2 - q_3^2) \quad \text{（无 $E_1$ 直接项）}
\end{aligned}}$$

红色项是 $E_1$ 的直接贡献。**仅涉及 $q_0 \leftrightarrow q_1$，不涉及 $q_2, q_3$。**

### 11.2 与之前错误版本的关键差异

| | 错误版 | 正确版 |
|---|---|---|
| $E_1$ 直接影响的分量 | $q_0,q_1,q_2,q_3$（四条通道） | **仅 $q_0,q_1$**（一条通道） |
| $q_2 \leftrightarrow q_3$ 耦合 | 直接：$-( |t_3|-E_1)q_3$ 和 $-E_1q_2$ | **无直接耦合，仅通过 $qBq$ 间接** |
| $E_1=|t_3|$ 的"临界点" | 存在（系数变号） | **不存在** |
| $\sigma_z$ 释放机制 | 线性通道打开 | **非线性反馈**：$E_1 \to q_0,q_1 \to qBq \to q_2,q_3 \to K_{\text{eff}}$ |

### 11.3 $E_1$ 的真正作用机制（间接反馈）

$$E_1 \;\xrightarrow{\dot q_0, \dot q_1}\; q_0,q_1 \text{ 轨迹改变} \;\xrightarrow{qBq}\; q_2,q_3 \text{ 轨迹改变} \;\xrightarrow{Bq}\; (K_{\text{eff}})_k \neq 0$$

$E_1$ 创建了 $q_0$–$q_1$ 之间的线性振荡（频率 $\sim E_1$），改变了 $q_0(t), q_1(t)$ 的时间轨迹。
这些改变通过 $qBq$ 中的 $q_0 q_2, q_0 q_3, q_1^2$ 等交叉项进入 $q_2, q_3$ 的演化。
最终 $Bq$ 产生非零的 $\mathbf{k}$ 分量，随时间积分后不再抵消（$A=D$ 对称性破缺）。

**这是纯非线性机制。** $E_1$ 不直接对 $q_2, q_3$ 施加力，而是通过改变 $q_0, q_1$ 来间接触发反馈回路。

### 11.4 参数区域分析（修正版）

物理尺度：$t_c = 0.3$ meV，$E_0 = 0.3$ meV。

#### 区域 A：$E_1 \ll |t_2|, |t_3|, |t_1|, E_d$（$E_1 \lesssim 0.01$ meV）

$q_0, q_1$ 受到 $E_1$ 的小扰动。由于 $E_1$ 效应通过 $qBq$（二次型）传递到 $q_2, q_3$，
$\sigma_z$ 净累积为 **$O(E_1^2)$**（而非 $O(E_1)$！）——因为 $q_0, q_1$ 的 $O(E_1)$ 修正
进入 $qBq$（$q$ 的二次型）后产生 $O(E_1^2)$ 的 $q_2, q_3$ 修正。

**小 $E_1$ 区域的 $v_y$ 应以 $E_1^2$ 标度增长**——可以用数值验证。

#### 区域 B：$E_1 \sim$ 其他耦合（$E_1 \sim 0.05$–$0.3$ meV）

$q_0$–$q_1$ 振荡不再可忽略。非线性反馈完全激活。$\sigma_z$ 净累积达到最大。
这是**全非线性区**——无解析处理，只能数值。

#### 区域 C：$E_1 \gg$ 所有其他耦合（$E_1 \gg 0.3$ meV）

主导运动是 $q_0$–$q_1$ 的快速振荡（$\omega \approx E_1$）：

$$\dot q_0 \approx E_1 q_1,\quad \dot q_1 \approx -E_1 q_0 \;\Longrightarrow\; q_0 \sim A\cos(E_1 t),\; q_1 \sim A\sin(E_1 t)$$

门控脉冲作为对 $(q_0,q_1)$ 振荡的缓慢调制。$qBq$ 项包含 $q_0 q_2, q_0 q_3, q_1^2$ 等——这些
含 $\cos(E_1 t), \sin(E_1 t)$ 的因子的乘积产生 $2E_1$ 频率的振荡。
$K_{\text{eff}}$ 的 $\mathbf{k}$ 分量的时间积分 $\propto \int \cos(E_1 t) dt \sim 1/E_1$，
随 $E_1$ 增大而抑制。但数值显示抑制不完全——$v_y$ 回落但非归零。

### 11.5 与数值的对照

| 预测 | 数值（`fig_e1_scan_v2.png`） |
|------|---------------------------|
| 小 $E_1$ 时 $v_y$ 从 0 开始增长 | ✅ 确认 |
| 小 $E_1$ 增长规律为 $O(E_1^2)$ | 待验证（可拟合 $\log v_y$ vs $\log E_1$） |
| 中等 $E_1$ 时 $v_y$ 达峰值后回落 | ✅ 确认（峰值在 $E_1 \sim 0.1$–$0.3$） |
| 大 $E_1$ 时 RWA 部分抑制 | ✅ 确认（$E_1=0.5$ 时 $v_y$ 明显低于峰值） |
| $E_1=|t_3|$ 无特殊临界行为 | ✅ 确认（无突变） |

## 十二、数值验证：$E_1$ 扫描

扫描 $E_1 \in [0, 0.5]$ meV，$\tau \in \{5, 15\}$，$t_1 \in \{0, 0.01, 0.05\}$。

### 12.3 修正

先前推测 $E_1 \gg t_c$ 时 RWA 会完全抑制 $v_y$。实际数值显示 $E_1 = 0.5$（≈ $1.7\,t_c$）时
$v_y$ 未归零——从峰值明显回落但不完全消失。RWA 抑制存在但不彻底。

### 12.4 统一物理图像

1. $E_1=0$：$A=D$，$\sigma_z$ 被脉冲对称性保护，$v_y=0$
2. $E_1$ 小：$-\mathbf{i}q$ 通道微弱打开，$q_2 \leftrightarrow q_3$ 弱耦合，$v_y$ 渐增
3. $E_1 \sim 0.1$–$0.3$：$-(|t_3|-E_1)$ 变号导致 $q_2$–$q_3$ 耦合方向翻转，**共振增强**，$v_y$ 达峰值
4. $E_1$ 继续增大：快振荡部分平均掉 $\sigma_z$ 累积，$v_y$ 从峰值回落
