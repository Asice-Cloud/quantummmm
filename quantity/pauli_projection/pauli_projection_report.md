# Pauli Projection K Extraction Report

## Summary

We extract K using Pauli projections from the Schur complement Σ(ω),
focusing on off-diagonal matrix elements that encode Majorana couplings.

## Key Results

- K_Pauli captures off-diagonal coupling structure: mean=3.048296e+00, std=1.767028e+00
- Pearson(K_Fro, N_Fro) = 0.027473
- Pearson(K_Pauli, N_Pauli) = -0.265784

## Interpretation

Pauli projection extracts coupling from matrix structure rather than global norms.
This may provide different scaling and physical interpretation compared to Frobenius.
