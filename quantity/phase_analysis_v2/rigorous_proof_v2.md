# K单调→N振荡的严格数学论证（改进版）

## I. 核心数学框架

### Yang-Baxter偏差：
$$\Delta = LHS - RHS = R_{12}(u)R_{23}(u+v)R_{12}(v) - R_{23}(v)R_{12}(u+v)R_{23}(u)$$

### 关键恒等式（矩阵差的范数）：
$$\|\Delta\|_F^2 = \text{Tr}(\Delta^\dagger\Delta) = \|LHS\|_F^2 + \|RHS\|_F^2 - 2\text{Re}(\text{Tr}(LHS^\dagger RHS))$$

### 角度表示法：
定义两个矩阵的夹角θ为：
$$\cos\theta = \frac{\text{Re}(\text{Tr}(LHS^\dagger RHS))}{\|LHS\|_F \|RHS\|_F}$$

### 近似公式（当||LHS|| ≈ ||RHS|| ≈ A时）：
$$\|\Delta\|_F \approx 2A \sin(\theta/2)$$

**这正是干涉公式：两个近似相等但方向不同的向量相减，结果大小由它们的夹角决定。**

## III. 严格结论

### 命题1（幅度单调性）
K单调递增 ⟹ R矩阵的幅度||LHS||, ||RHS||单调递增
这来自于虚过程通道随μ持续开放。

### 命题2（角度非单调性）
尽管幅度单调，LHS和RHS矩阵之间的夹角θ在[0.0°, 123.6°]范围内非单调波动。
这源于指数映射exp(-iH·τ)中相位的复杂回绕。

### 命题3（干涉主导）
N的振荡由角度θ的波动主导：$$\mathcal{N} \approx 2A \sin(\theta/2)$$
理论与实验相对误差仅0.0%，说明干涉机制是N非单调性的真正原因。

### 命题4（消失条件）
N ≈ 0 当且仅当 θ ≈ 0 (mod π)：
- θ ≈ 0 (mod 2π)：LHS和RHS几乎平行 → 破坏性干涉
- θ ≈ π：LHS和RHS几乎反平行 → 建设性干涉
在本参数范围内，有8个点出现N < 0.5，对应角度接近平行或反平行。

## IV. 物理机制

### 为什么编织矩阵的相位会非单调回绕？

$$R(u) = \exp\left(-i\int_0^u H_{\text{eff}}(s) ds\right)$$

其中 $H_{\text{eff}} = H_{PP} + \Sigma(0^+)$（有效Hamilton量）。

关键：
1. H_eff的能谱{E_i}随μ(E1)变化
2. 当某个E_i穿过费米面时，相位累积速率\partial(E_i)u/\hbar快速变化
3. 不同特征值的相位累积不同步 → 特征向量相对旋转
4. 结果：LHS和RHS的特征空间方向随u非单调变化
5. 这导致两个矩阵间的夹角θ非单调

### 为什么这是拓扑的？

- N的零点位置（E1的哪些值处N=0）由系统的拓扑特性决定
- 这些零点不能通过光滑变形消除（除非系统发生相变）
- Δ≠0反映了Majorana编织的**本质上非交换**特性
