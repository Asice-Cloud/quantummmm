# RE4：Fig.8-10 可比基准验证结果分析

## 1. 说明

这份记录总结当前模型针对论文 Fig.8、Fig.9、Fig.10 的**可比基准验证**结果。

这里的重点不是“严格复刻原图”，而是检查：

1. 当前模型能否在相同类型的观测量上给出稳定结果；
2. 哪些子图能够和论文建立可比关系；
3. 哪些子图已经暴露出当前模型与原文机制的差异。

## 2. 验证范围

本轮验证只检查“和当前模型可比”的观测量，包括：

1. 能谱随磁场或参数变化的结构；
2. 零偏导电图的整体形态；
3. 当前模型里可直接计算的非阿贝尔指示量 $\mathcal N$ 的样本行为；
4. 不同场景、不同参数扰动下的结构分离程度。

注意：

- 这里**没有**把论文中的所有子图都强行当成严格目标；
- 对于当前模型没有直接对应量的面板，只做趋势级比较。

---

## 3. Fig.8 的验证结果

### 3.1 能谱对比

结果显示，uniform 和 inhomogeneous 两种情形下的谱图相似但不完全相同。

数值上：
- 谱图相对差异为 $1.704045\times 10^{-3}$

这说明：

1. 当前模型在谱层面是有微小结构差别的；
2. 这种差别已经能被数值捕捉到；
3. 但差别并不大，属于“轻微区分”，不是强烈分裂。

### 3.2 零偏导电对比

零偏导电图的相对差异为：
- $8.490558\times 10^{-2}$

这是本轮 Fig.8 里最明确的差异之一，说明：

1. conductance-like 图对参数变化是敏感的；
2. 当前模型在零偏附近确实能表现出不同场景之间的可测差别；
3. 这一项可以作为后续论文对照的主要观察量之一。

### 3.3 零偏导电比例

零偏导电比值（inhomogeneous / uniform）为：
- $0.7048743$

这意味着：

1. 在当前模型中，inhomogeneous 情形并没有出现比 uniform 更强的零偏响应；
2. 这与论文中“inhomogeneous 更利于稳定 braiding / ZBP”的方向不完全一致；
3. 所以 Fig.8 只能算**部分匹配**，不能说已经完整复现了原文主张。

### 3.4 非阿贝尔指标 $\mathcal N$ 的样本

对三个采样点 $u=0.5, 2.0, 4.0$ 的 $\mathcal N$ 计算显示：

- uniform: $[0.162606, 10.063292, 40.79116]$
- inhomogeneous: $[0.160081, 9.950342, 40.198214]$

并且两组曲线都保持单调上升。

这说明：

1. 当前模型里的非阿贝尔指标具有良好的参数累积性；
2. 在路径参数增大时，指标确实持续增强；
3. 但 uniform 和 inhomogeneous 之间的差异仍然偏小。

### 3.5 Fig.8 的总体判断

Fig.8 是当前验证中**最接近论文 benchmark** 的一组，但仍然属于“趋势可比、机制不完全同构”的状态。

结论：
- 谱图趋势：基本可比；
- 导电图趋势：可比；
- 零偏增强方向：与论文不完全一致；
- $\mathcal N$：可以作为内部指标，但不能直接替代论文的 fidelity。

## 4. Fig.9 的验证结果

### 4.1 场景间 conductance map 的区分度

本轮验证中，六种场景的 conductance map 几乎完全相同：

- 平均 pairwise map difference = $0$
- 最大 pairwise map difference = $0$
- zero-bias conductance spread = $0$

这说明：

1. 当前模型对 Fig.9 中那种“多场景结构区分”的敏感性非常弱；
2. 也就是说，模型没有在这组场景上表现出论文里那种明显的分类度；
3. 这不是图画错了，而是当前模型机制本身对这些场景的响应太弱。

### 4.2 非阿贝尔指标的场景差异

尽管 conductance map 几乎不变，但采样的 $\mathcal N$ 还是有轻微变化：

- relative spread of sampled N values = $3.814702\times 10^{-2}$

说明：

1. 场景扰动对当前模型的代数指标有一定影响；
2. 但这种影响还不足以在 conductance 层面形成强区分；
3. Fig.9 目前只能算**弱可比**，不能算强 benchmark。

### 4.3 Fig.9 的总体判断

Fig.9 暴露出的主要问题是：

- 模型对不同结构场景的分辨能力还不够强；
- conductance map 的场景差异过弱；
- 这一组结果提示后续需要增强参数耦合方式或重新设计场景敏感的观测量。

结论：
- Fig.9 当前只能作为“结构扫描参考”；
- 还不能作为强验证基准。

## 5. Fig.10 的验证结果

### 5.1 disorder 场景下的零偏导电

在 disorder 场景中，zero-bias conductance 为：
- $1.813526\times 10^{-2}$

这个值并不大，但它不是零，说明：

1. 当前模型在 disorder 条件下仍保留可观测响应；
2. conductance map 并没有完全塌缩；
3. 这与论文中“扰动后仍保留可识别结构”的大方向是相容的。

### 5.2 $\mathcal N(\tau)$ 的参数响应

三组 $\delta$ 对应的 AUC 为：
- $[179.450194, 182.338131, 188.463211]$

这说明：

1. 随着 $\delta$ 增大，积分意义下的 $\mathcal N$ 是单调增强的；
2. 这与模型对扰动强度的响应方向是一致的；
3. $\mathcal N$ 可以作为一个“扰动强度指标”使用。

### 5.3 频谱对 $\delta$ 的敏感性

在三个代表性磁场点上，谱对 $\delta$ 的平均绝对位移为：
- $[0.021915, 0.021915, 0.021915]$

这说明：

1. 频谱对 $\delta$ 的变化是有稳定响应的；
2. 这个响应在三个磁场点上保持一致；
3. Fig.10 中最重要的“扰动下仍能看到结构变化”这一点是成立的。

### 5.4 Fig.10 的总体判断

Fig.10 是当前这轮验证里**最稳定的一组**：

1. disorder 下仍有可识别导电响应；
2. $\mathcal N$ 对 $\delta$ 呈现单调增强；
3. 频谱对参数扰动保持稳定位移。

结论：
- Fig.10 可以作为比较可靠的鲁棒性基准；
- 但仍然不能把 $\mathcal N$ 直接等同于论文的 fidelity。

## 6. 汇总判断

### 6.1 哪些部分通过得最好

1. **Fig.8 的 conductance 结构**：能够看到有效差异，属于可比基准；
2. **Fig.10 的扰动响应**：参数响应清晰，鲁棒性最强；
3. **$\mathcal N$ 的单调性**：内部代数指标本身是稳定的。

### 6.2 哪些部分仍然偏弱

1. **Fig.8 的零偏增强方向**：与论文不完全一致；
2. **Fig.9 的场景区分度**：几乎没有体现出来；
3. **$\mathcal N$ 与 paper fidelity 的对应**：仍然只是趋势级对应，不是严格等价。

---

## 7. 结论

本轮 Fig.8-10 验证表明：

1. 当前模型已经具备稳定的内部可比性；
2. Fig.8 和 Fig.10 可以作为主要 benchmark；
3. Fig.9 暂时只能作为弱 benchmark 或结构参考；
4. 模型的最大短板在于“不同场景的导电图区分度不够强”。

因此，下一步若要继续推进，最合理的路线是：

1. 保持 Fig.8 和 Fig.10 作为主验证对象；
2. 单独分析为什么 Fig.9 不敏感；
3. 再决定是否需要改进参数化或观测量定义。
