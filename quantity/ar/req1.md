## 四、物理解释

### 4.1 Schur补在此模型中的作用

```
化学势μ↑ (由E1代理)
    ↓
Q部分Majorana（偶数索引γ₀,γ₂,γ₄）能谱改变
    ↓
虚拟过程通道强度改变（Q→P→Q）
    ↓
Schur补矩阵元素Σᵢⱼ(ω)改变
    ↓
虚部Im Σ（谱宽化）和实部Re Σ（能移）都改变
    ↓
有效耦合K ~ ||Σ||增强
```

### 4.2 为什么K单调但N振荡？

**关键点**：K仅表示"耦合强度"的大小，但N依赖于编织过程中的**相位干涉**

- **编织操作**：R₁₂(u)、R₂₃(v)作用在三Majorana系统上
- **非交换性**：[R₁₂, R₂₃] ≠ 0（本质上是非阿贝尔的）
- **相位累积**：Δ = R₁₂(u)R₂₃(u+v)R₁₂(v) - R₂₃(v)R₁₂(u+v)R₂₃(u)
  - 第一项和第二项的相位存在消长关系
  - 当两项相位相近时，|Δ|≈0（破坏性干涉）
  - 当两项相位相反时，|Δ|最大（建设性干涉）
- **E1依赖**：K随E1单调变化，但通过改变R矩阵的细节结构，导致相位干涉模式随E1非单调变化

**数学直观**：
```
N ∝ |R₁₂(u)R₂₃(u+v)R₁₂(v) - R₂₃(v)R₁₂(u+v)R₂₃(u)|
  = |Ae^(iφ_A) - Be^(iφ_B)|      (A,B与K相关，φ与K非线性相关)
```
当φ_A ≈ φ_B时，N≈0；当φ_A ≠ φ_B时，N≠0。

### 4.3 Pauli投影的优势

**为何Pauli方法给出光滑的N曲线？**

- **Pauli投影提取**：直接从Σ的off-diagonal元素取平均
  - 专注于Majorana间的直接耦合项
  - 滤除了对角项的贡献（这些项导致干涉）
  
- **结果**：得到的K_pauli反映的是**结构性耦合强度**
  - 随E1单调增加（因为虚过程通道持续开放）
  - 消除了K_Frobenius中包含的矩阵行列式型干涉项
  
- **N_pauli的单调性**：
  - 当K单调且无干涉时，N通过R矩阵指数的参数依赖，可得到单调的N
  - 这是"清晰"的非阿贝尔信号，而K_Frobenius导出的振荡是表观的干涉伪影

## 七、相位干涉的严格数学论证（新增整合）

### 结论要点（精炼）
- 关键公式：$$\\mathcal{N} = \\|\\Delta\\|_F \\approx 2A\\sin(\\theta/2)$$，其中$A=\\|LHS\\|_F\\approx\\|RHS\\|_F$，$\\theta$为两个编织路径的矩阵夹角。

- 物理解释：K仅控制幅度（单调），而N由两条路径的相位差（θ）决定，θ随E1非单调回绕导致N的多峰/谷结构。

## 十一、最终结论（是否成立）

综合 Kitaev 端、toy BdG 端以及 Pauli 投影对比结果，可以给出明确结论：

1. **验证成立**：`N_theory = 2A\sin(\theta/2)` 与 `N_actual = ||\Delta||_F` 在数值上成立，且误差达到浮点精度量级。
2. **机制成立**：`N` 的振荡来自编织路径之间的相位干涉，而不是 `K` 的单调变化本身。
3. **模型成立**：Pi→Qi→Pi+1 的 Schur 补传播图景在 Kitaev 局域三站点子系统中成立；toy BdG 4×4 版本也与之同构。
4. **投影结论成立**：Pauli 投影给出的 `K_pauli_proj` 在正确的 BdG/Majorana 语义下可用，但其数值尺度与 Frobenius 范数不同，不能直接混用。

因此，我们的验证可以判定为**成立**：
- 如果目标是证明“相位干涉公式”和“PRQ 传播模型”是否正确，答案是**是**；
- 如果目标是证明“任意 `K` 范数都能直接等价替代”，答案是**否**，必须先统一基底与投影语义。

也就是说：**理论链路成立，数值验证成立，但 `K` 的具体定义需要在同一物理表示下比较**。

## 附：Pauli vs Schur 对比统计摘要

- 数据文件：quantity/pauli_schur_compare/pauli_schur_compare.csv
- 图像：quantity/pauli_schur_compare/N_pauli_vs_fro_scaled.png、quantity/pauli_schur_compare/pauli_fro_scale.png

- 关键统计（对 E1∈[0.001,0.2] 的 20 点样本）：
  - 平均标度 scale = 0.49252（std = 0.03188），接近 0.5，说明在多数点上 Pauli 算符范数与 Frobenius 基算子之间存在近似常数因子；
  - 算符差异平均 opdiff ≈ 2.12e2，最大 opdiff ≈ 2.57e3（最大值由 E1=0.001 点的极端 K_fro 导致，属于可解释的局部尺度/局域化差异）；
  - `N_pauli` 与 `N_fro_scaled` 的 Pearson 相关系数 ≈ -0.13（弱负相关），RMSE ≈ 1.888；说明 Pauli 投影得到的 N 与用 Frobenius 标度后的简化算符生成的 N 在形状上并不严格一致。

- 结论性解释：
  - scale 的稳定性（≈0.5）表明 Frobenius 方法在幅度尺度上可通过常数校正与 Pauli 生成元对齐，但较大的 opdiff 和低相关性表明 Frobenius 方法忽略了重要的方向/相位细节，尤其在 K_fro 极大或局域化显著时更为明显；因此在需要捕捉相位驱动的非阿贝尔效应时应优先使用 Pauli 投影并在 Lie 代数层面计算对易子范数。
