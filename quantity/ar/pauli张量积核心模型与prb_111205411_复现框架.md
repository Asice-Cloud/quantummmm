# Pauli张量积核心模型与 PRB 111.205411 复现框架

---

# 0. 模型目标

构建一个以 Pauli 张量积为核心的 non-Abelian 模型：

\[
\boxed{
\mathcal H=(\mathbb C^2)^{\otimes N}
}
\]

并实现：

1. logical braid evolution
2. PRP/PHP closure
3. Schur-complement leakage
4. ABS/MZM 区分
5. non-Abelian braid quantification
6. PRB 111.205411 数值复现

核心思想：

\[
\boxed{
\text{non-Abelianity} = \text{tensor-operator braid stability}
}
\]

而不是单纯 Majorana 零模。

---

# 1. Hilbert空间

定义：

\[
\mathcal H=(\mathbb C^2)^{\otimes N}
\]

维数：

\[
\dim \mathcal H=2^N
\]

标准 Pauli 基：

\[
\sigma^0=I,
\quad
\sigma^x,
\sigma^y,
\sigma^z
\]

完整张量基：

\[
\boxed{
\mathcal P_N=
\{
\sigma^{a_1}\otimes\sigma^{a_2}\otimes\cdots\otimes\sigma^{a_N}
\}
}
\]

其中：

\[
a_i\in\{0,x,y,z\}
\]

---

# 2. Hamiltonian（Pauli张量积表示）

定义一般 Hamiltonian：

\[
\boxed{
H(u)=\sum_\alpha J_\alpha(u) P_\alpha
}
\]

其中：

\[
P_\alpha\in\mathcal P_N
\]

路径参数：

\[
u\in[0,U]
\]

所有 braid / exchange 结构由：

\[
J_\alpha(u)
\]

控制。

---

# 3. 最小链模型

构造 nearest-neighbor Pauli Hamiltonian：

\[
\boxed{
H(u)=
\sum_i
\Big[
J_x(u)\sigma_i^x\sigma_{i+1}^x
+
J_y(u)\sigma_i^y\sigma_{i+1}^y
+
J_z(u)\sigma_i^z\sigma_{i+1}^z
\Big]
+
\sum_i h_i(u)\sigma_i^z
}
\]

---

# 4. logical子空间

定义低能逻辑空间：

\[
\boxed{
P=\sum_{a=1}^k |\psi_a\rangle\langle\psi_a|
}
\]

其余部分：

\[
Q=I-P
\]

于是：

\[
\mathcal H=\mathcal H_P\oplus\mathcal H_Q
\]

---

# 5. P/Q block decomposition

Hamiltonian 写成：

\[
H=
\begin{pmatrix}
H_{PP} & H_{PQ} \\
H_{QP} & H_{QQ}
\end{pmatrix}
\]

其中：

\[
H_{PQ}=PHQ
\]

表示：

- logical ↔ bulk leakage
- ABS mixing
- braid deformation

---

# 6. Schur complement

Green函数：

\[
G(z)=(z-H)^{-1}
\]

投影 Green函数：

\[
\boxed{
G_{PP}(z)=
(z-H_{PP}-\Sigma(z))^{-1}
}
\]

其中：

\[
\boxed{
\Sigma(z)=H_{PQ}(z-H_{QQ})^{-1}H_{QP}
}
\]

---

# 7. Pauli表示中的Σ(z)

由于：

\[
H_{PQ}=\sum_\alpha c_\alpha P_\alpha
\]

因此：

\[
\Sigma(z)
=
\sum_{\alpha\beta}
 c_\alpha c_\beta
 P_\alpha
(z-H_{QQ})^{-1}
P_\beta
\]

于是：

\[
\boxed{
\Sigma(z)
=
\text{operator-valued tensor algebra}
}
\]

这是 Pauli 表示最重要的优势。

---

# 8. 路径演化算符

定义：

\[
\boxed{
R(u)=
\mathcal T
\exp
\left(
-i\int_0^u H(s)ds
\right)
}
\]

有效演化：

\[
R_{eff}(u)=
\mathcal T
\exp
\left(
-i\int_0^u(H_{PP}+\Sigma(s))ds
\right)
\]

---

# 9. braid generator

定义局域 braid operator：

\[
\boxed{
B_i(u)=e^{i\theta(u)\sigma_i^\alpha\sigma_{i+1}^\beta}
}
\]

---

# 10. Yang–Baxter结构

定义 braid deviation：

\[
\boxed{
\Delta_{YB}
=
B_iB_{i+1}B_i
-
B_{i+1}B_iB_{i+1}
}
\]

定义 non-Abelian measure：

\[
\boxed{
\mathcal N
=
\|\Delta_{YB}\|
}
\]

---

# 11. PRP closure

定义：

\[
PR(u)P
\]

---

# 17. Pauli表示相对于Majorana表示的优势

---

## 17.1 algebra显式化

Pauli 算符满足：

\[
[\sigma^\alpha,\sigma^\beta]
=
2i\epsilon_{\alpha\beta\gamma}\sigma^\gamma
\]

因此：

- braid algebra显式
- YBE结构显式
- commutator结构显式

---

## 17.2 tensor geometry

logical manifold：

\[
(\mathbb C^2)^{\otimes N}
\]

于是：

- subspace projection自然
- PRP结构自然
- leakage结构自然

---

## 17.3 non-Abelian量化更直接

因为：

\[
B_i=e^{i\theta \sigma_i\sigma_{i+1}}
\]

可直接构造：

\[
B_iB_jB_i-B_jB_iB_j
\]

无需隐式 Clifford 结构。

---

## 17.4 数值实现更容易

Pauli tensor形式天然适合：

- exact diagonalization
- tensor network
- quantum circuit simulation
- operator evolution
