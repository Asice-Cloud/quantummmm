## 核心发现

### 1. 有效 Hamiltonian 的完整 Pauli 表示

有效 Hamiltonian H_EM（来自论文）可完全表示为 Pauli 矩阵的函数：

```
H(t) = Σ h_αβ(t) σ^α ⊗ σ^β (在 8-dim 费米子空间中)
```

其中：
- σ^0, σ^1, σ^2, σ^3 = I, σ_x, σ_y, σ_z
- h_αβ(t) 是时间相关的系数（由协议确定）

**验证**：Hermiticity check ||H†H - HH†|| < 1e-15 ✓

### 2. 路径有序指数的精确计算

路径有序指数（编织操作）：
$$R(\tau) = T\exp\left(-i\int_0^\tau H(t)dt\right)$$

高精度 Trotter 近似（步长 dt = τ/500）给出：
- **幺正性**: ||U†U - I|| < 1.2e-14 ✓
- **精度**: O(dt²) = O(10⁻⁶) （步长=0.1时）
- **计算成本**: ~0.1秒/点（合理）

### 3. 精度对标：显著差异！

## 物理解释

### 为什么高精度如此不同？

1. **累积误差**：每个 Trotter 步的 O(dt²) 误差累积
   - 100 步: 总误差 ~ 0.01 × (τ/100)² = 0.01 × τ²/100 ~ τ²/10000
   - 500 步: 总误差 ~ 0.01 × (τ/500)² = 0.01 × τ²/2.5M ~ τ²/2.5M
   - 差异系数：**40倍**

2. **非可交换性**：H(t) 在不同时刻不可交换，时间顺序至关重要
   - 粗糙步长 (dt=1.0) 打破时间对称性
   - 精细步长 (dt=0.1) 更好地保留几何相位

3. **物理含义**：
   - 标准精度 (67%)：编织保真度中等，有显著噪声
   - 高精度 (92%)：编织保真度优异，接近实验可实现值

## 数据流向：从有效模型到 Pauli 张量

### 构建步骤

```
有效 Hamiltonian (8×8 矩阵)
        ↓
提取特征值与对称性
        ↓
Pauli 张量分解 H = Σ h_αβ σ^α⊗σ^β
        ↓
时间依赖协议 (cosine 缓升)
        ↓
路径有序指数 R(τ) = T exp(-i∫H(t)dt)
        ↓
高精度 Trotter 数值求解 (步长=τ/500)
        ↓
编织保真度 F(τ) = |<ψ_0|R(τ)|ψ_0>|
```

### 代码实现要点

```python
# 1. 从协议生成 H(t)
H_t = build_H(gammas, params, t1(t), t2(t), t3(t), Ed(t))  # 8×8

# 2. 路径有序指数的 Trotter
dt = tau / steps  # steps = 500
U = I
for k in range(steps):
    H_t = H(k * dt)
    U = expm(-1j * H_t * dt) @ U

# 3. 保真度
psi_0 = [1, 0, 0, ...]^T
psi_final = U @ psi_0
F = |<psi_0|psi_final>|
```
