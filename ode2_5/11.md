# 纤维联络的严格证明与弯曲结构

---

## 一、纤维联络的显式公式（严格证明）

### 定理

设 $U(t) \in Sp(2)$ 满足 $\dot U = K U$，其中 $K = \begin{pmatrix}A&B\\ C&D\end{pmatrix} \in \mathfrak{sp}(2)$。
将 $U$ 沿主丛 $Sp(2) \to \mathbb{HP}^1$ 分解为 $U = \sigma(q) \cdot h$，$h = \operatorname{diag}(u,v) \in U(2)$。
则 MZM 纤维的 Maurer-Cartan 形式为：

$$\boxed{\omega_u \equiv \dot u u^{-1} = \operatorname{Im}(A + Bq)}$$

ancilla 纤维同理：$\omega_v = \operatorname{Im}(D + Cp)$，其中 $p = YW^{-1}$。

### 证明

**步骤 1**：$u = X/|X|$ 是单位四元数。

由 $Sp(2)$ 条件 $U^\dagger U = I$ 的 (1,1) 块：$|X|^2 + |Z|^2 = 1$，故 $|u| = 1$。

**步骤 2**：计算 $\dot u u^{-1}$。

$$\dot u = \frac{\dot X}{|X|} - X\frac{|\dot X|}{|X|^2}, \qquad \dot u u^{-1} = \dot X X^{-1} - \frac{|\dot X|}{|X|}I$$

由 $\dot X = AX + BZ$ 及 $Z = qX$：$\dot X = (A+Bq)X \equiv K_{\text{eff}} X$，故 $\dot X X^{-1} = K_{\text{eff}}$。

$$\dot u u^{-1} = K_{\text{eff}} - \frac{|\dot X|}{|X|}I$$

**步骤 3**：标量部分相消。

$u$ 是单位四元数 $\Rightarrow$ $\dot u u^{-1}$ 纯虚 $\Rightarrow$ $|\dot X|/|X| = \operatorname{Re}(K_{\text{eff}})$。

验证：由 $|X| = 1/\sqrt{1+|q|^2}$ 得 $|\dot X|/|X| = -q\!\cdot\!\dot q/(1+|q|^2)$。
由 Riccati 方程及 **$\mathfrak{sp}(2)$ 条件 $C = -\bar B$**（$c_0 = -b_0, c_3 = b_3$）：

$$(b_0 q_0 - b_3 q_3)(1+|q|^2) + q\!\cdot\!\dot q = b_0 q_0 - b_3 q_3 + c_0 q_0 + c_3 q_3 = 0$$

sympy 验证精确成立。

**步骤 4**：$\omega_u = \operatorname{Im}(K_{\text{eff}}) = \operatorname{Im}(A + Bq)$。$\square$

### 分量展开

代入物理 $A, B$：

$$\boxed{\begin{aligned}
\omega_u^{(i)} &= \frac{E_1 + |t_3|}{2} + \frac{|t_1|}{2}q_1 - \frac{E_d}{2}q_2 \\[4pt]
\omega_u^{(j)} &= \frac{|t_2|}{2} + \frac{|t_1|}{2}q_2 + \frac{E_d}{2}q_1 \\[4pt]
\omega_u^{(k)} &= \frac{|t_1|}{2}q_3 + \frac{E_d}{2}q_0
\end{aligned}}$$

同理：

$$\boxed{\omega_v = \operatorname{Im}(D + Cp)}$$

## 二、$E_1=0$ 时纤维平坦

$\omega_u^{(k)}$ 不显含 $E_1$。$E_1=0$ 时 $A=D$，Riccati 方程 $\dot q = C + [A,q] - qBq$ 保证：

$$\frac{\dot\alpha}{|t_2|} = \frac{\dot\beta}{|t_3|}$$

从而 $|t_3|\beta - |t_2|\alpha \equiv 0$。三步脉冲对称性 $\int f_m = \int f_p$ 使得：

$$\int_0^{3\tau} \omega_u^{(k)}(t) dt = 0, \quad \forall\, t_1$$

$$\boxed{\left.\frac{\partial\theta_u}{\partial t_1}\right|_{E_1=0} = 0, \qquad \left.\frac{\partial\theta_v}{\partial t_1}\right|_{E_1=0} = 0}$$

## 三、$E_1 > 0$ 时联络弯曲

### 3.1 弯曲的结构形式

将 $\theta_u(E_1, t_1)$ 在 $E_1=0$ 附近展开：

$$\boxed{\theta_u(E_1, t_1) = \theta_u^0 + E_1 \cdot f(t_1) + O(E_1^2)}$$

- $\theta_u^0 = \theta_u(0, t_1)$ 是常数（平坦性）
- $f(t_1) = \partial\theta_u/\partial E_1|_{E_1=0}$，满足 $f(0)=0$
- $f(t_1)$ 无解析闭式（Riccati 方程非可积），可从数值提取

### 3.2 弯曲的来源

$E_1$ 出现在两处：

1. **直接**：$\omega_u^{(i)}$ 中多出 $E_1/2$ 项
2. **间接**：$A \neq D$ 打破 $\dot\alpha/|t_2| = \dot\beta/|t_3|$，改变整个 $q(t)$ 轨迹，进而改变 $\int \omega_u^{(k)} dt$

$\omega_u^{(k)}$ 本身不显含 $E_1$——弯曲完全来自 $q(t)$ 轨迹的偏移。

### 3.3 弯曲强度的表征

定义弯曲度：

$$\kappa(E_1, t_1) = \frac{\partial\theta_u}{\partial t_1}$$

- $E_1=0$：$\kappa = 0$
- $E_1>0$：$\kappa \neq 0$，其等值线在热力图中呈对角带

### 3.4 $E_1=0$ vs $E_1>0$ 对比

| | $E_1=0$ | $E_1>0$ |
|---|---|---|
| $A$ vs $D$ | $A=D$ | $A \neq D$（差 $E_1\mathbf{i}$） |
| Riccati 线性项 | $[A,q]$（纯旋转） | $Dq-qA$（旋转+破缺） |
| $\dot\alpha/|t_2|$ vs $\dot\beta/|t_3|$ | 相等 | 不等 |
| $\int\omega_u^{(k)}dt$ | $0$（与 $t_1$ 无关） | $\neq 0$（依赖 $t_1$） |
| $\theta_u(E_1,t_1)$ | 常数 | $\theta_u^0 + E_1 f(t_1) + \cdots$ |

## 四、证明中的关键恒等式

| 恒等式 | 依赖条件 |
|--------|---------|
| $\dot u u^{-1}$ 纯虚 | $u$ 是单位四元数 |
| $\operatorname{Re}(K_{\text{eff}}) = |\dot X|/|X|$ | $\mathfrak{sp}(2)$ 条件 $C = -\bar B$ |
| $\int \omega_u^{(k)} dt = 0$（$E_1=0$） | $A=D$ + 三步脉冲对称性 |
| $\partial\theta_u/\partial t_1 = 0$（$E_1=0$） | 上述恒等式 + $f_m, f_p$ 对称 |
