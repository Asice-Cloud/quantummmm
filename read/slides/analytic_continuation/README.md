## Overleaf 编译

1. 新建项目，选择 **Upload Project**，上传 `prb111_fidelity_overleaf.zip`。
2. 主文件设为 **main.tex**，编译器设为 **XeLaTeX**。
3. 使用近期 TeX Live 编译。页码总数通常需两轮 LaTeX，Overleaf 会自动处理。

中文采用 TeX Live 自带 Fandol 字体；所有图片在 `figures/` 中，使用相对路径。无需额外字体、Python、BibTeX 或 shell escape。编译结果为 16:9 PDF 幻灯片。

## 修改入口

- `main.tex`：全部幻灯片；顶部的 `\PresenterName`、`\PresentationDate` 可填写姓名和日期。
- `style.tex`：颜色、字体、页脚及通用命令。
- `figures/frame_panels.png`：brief 中平行输运图的三个面板，裁掉重复的大标题和页脚。
- 其余三个 PDF 图片对应 brief 第 5 部分的热图、因子 2 试画与截面图。

因子 2 的图保留在第 5 部分，标明是试画；它不改变正文公式或原验证表。3.2 明确区分参数与时间变量；3.3 列出低能态计数，并从单圈矩阵直接用哈密顿–凯莱恒等式推导读出，不引入连接矩阵。这些说明已同步到 brief。
