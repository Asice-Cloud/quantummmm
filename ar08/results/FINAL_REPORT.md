## How the code implements the model (简要复述)

1. Construct tetron gate path (`tools/tetron_path_sim.py`) → produce time series g1..g4 and phase `theta(t)`.  
2. Map gates → lattice parameters via `map_gates_to_links()` in `tools/reproduce_figs.py` → produce `mu`, `t_links`, `Delta_links`.  
3. BdG path: `tools/embed_kitaev.build_bdg()` 构造 2L×2L BdG 矩阵，求本征值/本征向量以获得 `E_bdg(t)` 与 LDOS。  
4. Pauli 映射: 用线性系数 A0,B0,C0 把 `S(t)=t_left+t_right`, `M(t)=mu1-mu2`, `theta(t)` 映射到 `d_x,d_y,d_z`，构造 2×2 Hamiltonian 做时间推进（`expm(-iH dt)`) 得到最终态与 Bloch 向量。  
5. 拟合与对齐: 用最小二乘拟合 `E_pred(t)` 与 `E_bdg(t)`（或后续用 overlap/LDOS 目标）得到映射常数，保存为 `results/*.npz`。
