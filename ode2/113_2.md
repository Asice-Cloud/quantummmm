# SI.pdf 的 Riccati ODE 完整推导

> 用 Riccati 方程视角重构 Nitsch PRB 113 的完整推导

## 1. Sp(2) 群与 Riccati 方程

### 1.1 辛群结构

$U \in \mathrm{Sp}(2)$ 是 $2\times2$ 四元数矩阵，$U^\dagger J U = J$ with $J = \begin{pmatrix}0&1\\-1&0\end{pmatrix}$：

$$U = \begin{pmatrix} X & Y \\ Z & W \end{pmatrix}, \quad X,Y,Z,W \in \mathbb{H}$$

辛条件：$|X|^2 - |Z|^2 = 1$, $\bar{X}Y = \bar{Z}W$, $\bar{X}W - \bar{Z}Y = 1$。

Lie 代数元素 $K = \dot{U} U^{-1} \in \mathfrak{sp}(2)$：

$$K = \begin{pmatrix} A & B \\ C & D \end{pmatrix}, \quad A^\dagger = -A,\; D^\dagger = -D,\; C = -B^\dagger$$

### 1.2 Riccati 变量

$q = Z X^{-1} \in \mathbb{H}$（4 实分量）。演化：

$$\boxed{\dot{q} = C + Dq - qA - qBq}$$

$qBq$ 是 $\mathrm{Sp}(2)/H$ 商空间投影的几何代价。在 $G$ 上 $\dot{U}=KU$ 是线性的。

### 1.3 Möbius 类型

辛条件 $C = -B^\dagger$。根据 $B$ 和 $C^\dagger$ 的相对符号：

| 类型 | 条件 | 几何 | 轨道 |
|---|---|---|---|
| **椭圆** | $B = +\kappa C^\dagger$, $\kappa>0$ | 旋转 | $q$ 有界（紧致） |
| **双曲** | $B = -\kappa C^\dagger$, $\kappa>0$ | Boost | $q$ 可逃逸（非紧） |

## 2. $\tau_{12}$ 的 Riccati 方程

### 2.0 协议参数 $\rho_k$

$\rho_k$ 是 Nitsch 协议的无量纲耦合参数（SI Eq. S10）：

$$\rho_1 = \frac{\epsilon_1}{\Delta}, \quad \rho_2 = \frac{t_{12}}{\Delta\sqrt{1+\zeta^2}}, \quad \rho_3 = \frac{t_{13}}{\Delta\sqrt{1+\zeta^2}}$$

满足 $\rho_1^2+\rho_2^2+\rho_3^2=1$（保持能隙 $\Delta$ 恒定），用球坐标参数化：

$$\rho_1=\cos\theta,\quad \rho_2=\sin\theta\cos\phi,\quad \rho_3=\sin\theta\sin\phi$$

- $\theta=0$：$\rho_1=1,\rho_2=\rho_3=0$ → 只有 $\gamma_1$-$\tilde{\gamma}_1$ 耦合，子系统 L 和 R 完全隔离 → $q=ZX^{-1}=0$
- $\theta=\pi/2$：$\rho_1=0$ → $\gamma_1,\tilde{\gamma}_1$ 解耦，仅与 $\gamma_2$（或 $\gamma_3$）耦合

$\tau_{12}$ 步 $\phi=0$，哈密顿量仅依赖 $\rho_1=\cos\theta,\rho_2=\sin\theta$。

### 2.1 哈密顿量 → Sp(2) 矩阵

活跃 Majorana $\{a,b,c,d\} = \{\gamma_1,\tilde{\gamma}_1,\gamma_2,\tilde{\gamma}_2\}$。分块 L=$\{a,b\}$, R=$\{c,d\}$。

$h = \cos\theta\cdot iab + \sin\theta\cdot iac + \eta\sin\theta\cdot ibd + \lambda\cdot icd$。

$iab$ (L-L) → $A$ 块，$iac$ (L-R) → $B$ 块，$ibd$ (L-R) → $B$ 块，$icd$ (R-R) → $D$ 块。

在标准 Spin(4) 表示下（$\gamma$ 矩阵用 Pauli 实现），每个 $i\gamma_p\gamma_q$ 映射到 Sp(2) 的四元数矩阵。保留符号和结构：

$$\boxed{\begin{aligned}
A(\theta) &= \frac{i}{2}(\lambda + \cos\theta)\mathbf{1} \\
D(\theta) &= \frac{i}{2}(\lambda - \cos\theta)\mathbf{1} \\
B(\theta) &= \frac{i}{2}(1-\eta)\sin\theta\;\mathbf{j} \\
C(\theta) &= -B^\dagger = -\frac{i}{2}(1-\eta)\sin\theta\;\mathbf{j}
\end{aligned}}$$

### 2.2 Riccati 方程

代入 $\dot{q} = C + Dq - qA - qBq$：

$$\boxed{\dot{q} = -\frac{i}{2}(1-\eta)\sin\theta\,\mathbf{j} + \frac{i}{2}(\lambda-\cos\theta)q - q\frac{i}{2}(\lambda+\cos\theta) - q\frac{i}{2}(1-\eta)\sin\theta\,\mathbf{j}\,q}$$

初始条件：$\rho_1=1$ 时子系统解耦，$q(0)=0$。

## 3. $\lambda$ 条件

### 3.1 小 $\eta$ 分析

$\eta \ll 1$ 时 $q \sim \mathcal{O}(\eta)$。保留线性项：

$$\dot{q}_2 \approx -\tfrac{1}{2}\sin\theta - \cos\theta\,q_0, \quad \dot{q}_0 \approx -\lambda\,q_2$$

$\dot{q}_0$ 的抑制要求 $|\lambda| \sim \mathcal{O}(\eta)$，否则 $q_0$ 被 $\lambda q_2$ 放大。

### 3.2 $\mathbf{J}$-$\mathbf{K}$ 分解条件

李代数分解给出 $\mathbf{b} = (0, -\sin\theta(1-\eta), \cos\theta-\lambda)$。$\mathbf{b}=0$ 要求 $\lambda=\eta\cos\theta$。取协议平均：

$$\boxed{\lambda_{\text{opt}} = \eta\cdot\frac{2}{\pi}\int_0^{\pi/2}\cos\theta\,d\theta = \frac{2\eta}{\pi} \approx 0.637\eta}$$

### 3.3 Riccati 条件

**$\lambda$ 使 $|q(\theta;\lambda)|$ 在整个 $\theta\in[0,\pi/2]$ 上取极小。**

数值上扫描 $\lambda$，找 $\max_\theta|q(\theta)|$ 最小的值。此条件下 $B$ 的 $\mathbf{K}$ 贡献被抵消：

$$B = B_J, \quad C = B_J^\dagger \quad\text{(纯椭圆 Möbius)}$$

---

## 4. Berry 相位

### 4.1 椭圆 Möbius 可积性

$B = B_J$, $C = B_J^\dagger$ 时，Riccati 方程等价于 $\dot{U}_J = K_J U_J$，其中 $U_J \in \mathrm{SU}(2)$（$\mathbf{J}$ 子群）。$U_J$ 是 3D 旋转。

### 4.2 几何角

参数路径 $\theta:0\to\pi/2$。$\mathbf{J}$ 部分的等效磁场方向从 $(0,0,1)$ 旋转到 $(0,-1,0)$（忽略 $\eta$ 修正），在 Bloch 球上扫过 $90^\circ$ = $\pi/2$。

闭合路径（三步协议）的立体角：$\Omega = 3 \times \pi/2 = 3\pi/2$。每步 Berry 相位 $\gamma = \Omega/(2\cdot 3) = \pi/4$。

### 4.3 解

$$\boxed{U_{12} = \exp\!\left(\frac{\pi}{4}\,\gamma_2\tilde{\gamma}_1\right)}$$

## 5. 完整协议

### $\tau_{23}$（双 $\mathfrak{so}(3)$ 分解）

- 块 A：$U_A = \exp(\frac{\pi}{4}\gamma_3\gamma_2)\exp(-\frac{\pi}{4}\nu(\mu\gamma_3\tilde{\gamma}_1+\nu\gamma_3\gamma_2))$
- 块 B：$U_B = \exp(\frac{\pi}{4}\tilde{\gamma}_3\tilde{\gamma}_2)\exp(\frac{\pi}{4}\alpha(\beta\tilde{\gamma}_3\gamma_1-\alpha\tilde{\gamma}_3\tilde{\gamma}_2))$

### $\tau_{31}$（对称性）

$U_{31} = \exp\!\left(\frac{\pi}{4}\,\tilde{\gamma}_1\gamma_3\right)$

### 完整编织

$$\boxed{U(\eta) = \exp\!\left(\frac{\pi}{4}\,\gamma_3\gamma_2\right) \cdot \exp\!\left(\tilde{\varphi}(\eta)\,\tilde{\gamma}_3\tilde{\gamma}_2\right)}$$

其中 $\tilde{\varphi} = \arcsin\!\left(\frac{2\eta}{1+\eta^2}\right)$，双次 fidelity $S = \left(\frac{2\eta}{1+\eta^2}\right)^4$。
