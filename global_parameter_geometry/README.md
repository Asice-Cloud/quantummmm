# 全参数域的状态演化与峰线几何

本文件夹研究一个具体问题：在既定的六段协议下，能否从完整状态场

\[
\mathcal B(E_1,|t_1|,t\mid\tau,t_c,E_0)
\]

统一描述一整片参数区域内的保真度条带，得到峰的位置、间距、高度及其变化，并判断这些结论的误差？

这里的“全域”指选定有限参数区域 \(\Omega\) 上的整体结构。任意扩大区域和演化时间，通常需要更多展开项；本轮没有预设一个有限阶公式能覆盖整个无界参数平面。

## 阅读顺序

1. [全域状态方程与误差控制](spectral_state_equations.md)：从原始状态方程推导参数谱系数的演化，说明初值、六段接口、几何约束和误差界。
2. [峰线几何与第一项验证](peak_geometry_and_validation.md)：把状态场转成峰线、峰高和分支变化的判据，并确定第一项可检验任务。
3. [从全域系数到峰线](global_peak_bounds.md)：推导 Gauss 节点等价关系、先验阶数与完整误差界，并把峰的倾斜和高度变化写成状态曲面的几何量。

## 本轮采用的设置

| 项目 | 约定 |
|---|---|
| 不可控参数 | \(E=E_1\)、\(\eta=|t_1|\)，在一次演化内保持常数 |
| 可控设计量 | 保留 \(\tau,t_c,E_0\) 的符号 |
| 时间 | 真实演化时间 \(t\in[0,6\tau]\)，共六段 |
| 门控 | 沿用原来的余弦包络，三段协议重复两次 |
| 生成元 | 由有效哈密顿量得到的 \(K=2A\) |
| 完整状态 | \(\mathcal B\) 的十个反对称分量 \(\mathbf b\) |
| 保真度记号 | \(F\) 为平方重叠；与论文色标对应的量为 \(f=\sqrt F\) |
| 第一次数值验证的设计值 | 拟沿用 \(\tau=100/\mathrm{meV}\)、\(t_c=E_0=0.3\,\mathrm{meV}\) |

\(K=A\) 的归一化比较属于此前诊断，不作为本轮的物理方程。与论文比较时，仍按图注使用 \(E_1=0.01\,\mathrm{meV}\)；本轮首先验证模型内部的全域分析方法。

## 思路的实质

现有方程对有限 \(E,\eta\) 已经成立，困难在于如何提取整个参数区域的结构。本轮利用生成元对两个参数的仿射依赖，把整个状态场展开成 Legendre 多项式的系数。各阶系数只与相邻阶耦合，因此可以统一求解整个区域，并直接求参数导数。

无限阶展开与原方程等价，有限阶截断才产生近似。这个展开不要求 \(E\tau\) 或 \(\eta\tau\) 为小量，也不是在一个参数点截取少数阶 Taylor 项。

接下来用 \(F_\eta=0\)、\(F_{\eta\eta}<0\) 跟踪沿 \(\eta\) 方向的峰线，结合状态到目标的几何距离解释峰高。误差控制既覆盖状态与保真度，也覆盖梯度、曲率；后两者决定峰线和峰数判断是否可靠。

这仍然保留时间演化。谱系数方程是原参数化演化方程的整体表示，没有新增独立的参数扩散定律，也尚未得到只含终点 \(F(E,\eta)\) 的闭合标量 PDE。

## 当前进度

| 内容 | 状态 |
|---|---|
| 原模型、十分量状态方程、保真度读出 | 沿用此前已核对的结果 |
| 全域谱系数方程、初值和接口 | 已推导 |
| Legendre 递推、矩阵分解、截断生成元的反对称性 | 已作代数核对 |
| 全阶参数导数上界、状态及响应的残差误差界 | 已给出解析推导 |
| Gauss 节点等价关系、全域插值及导数的先验误差界 | 已推导并核对变换与余项公式的实现 |
| 首轮参数域的阶数估计 | 已计算；24 阶的参数截断上界满足既定状态与导数目标，时间求解误差仍需另计 |
| 峰线斜率和峰高与状态度量、弯曲项的关系 | 已推导；尚未代入新的状态解计算峰线 |
| 完整的六段谱系数数值演化 | 待实现 |
| 一条完整峰线及其误差验证 | 下一项任务 |
| 更大区域内所有峰的枚举、退化点分类 | 后续任务，尚未完成 |

第一项任务的成功标准是：在一块有限区域内，得到可重复、随展开阶数收敛的峰线位置与峰高，并明确误差依据。热图相似和少数抽样点一致只能提供部分证据。

最新的 [误差公式计算脚本](derive_global_error_bounds.py) 与 [数值表](bounds_at_tau100.json) 只评估解析上界，没有运行完整状态演化。先验估计支持首先比较 20 阶与 24 阶；不能将其中的截断误差上界解释为已经得到的峰线误差。
