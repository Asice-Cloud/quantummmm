Mapping HP -> i * sum_{a<b} A_ab gamma_a gamma_b  (A_ab in terms of c_xx,c_yy,c_xy,c_yx):

A_(1, 2) = 0
A_(1, 3) = -I*c_xx
A_(1, 4) = -I*c_xy
A_(2, 3) = -I*c_yx
A_(2, 4) = -I*c_yy
A_(3, 4) = 0

Expanded HP (monomial -> coeff):
(1, 3): c_xx
(1, 4): c_xy
(2, 3): c_yx
(2, 4): c_yy

Representation of HP in fermionic bilinear basis (coefficients for [n1,n2,hop1,hop2,pair1,pair2]):
n1: 0
n2: 0
hop1: c_xx + I*c_xy - I*c_yx + c_yy
hop2: c_xx - I*c_xy + I*c_yx + c_yy
pair1: c_xx - I*c_xy - I*c_yx - c_yy
pair2: c_xx - c_yy + I*(c_xy + c_yx)

Interpreting BdG-like parameters (raw coefficients):
mu1 (n1): 0
mu2 (n2): 0
hop c1d*c2 (hop1): c_xx + I*c_xy - I*c_yx + c_yy
hop c1*c2d (hop2): c_xx - I*c_xy + I*c_yx + c_yy
pair c1d*c2d (pair1): c_xx - I*c_xy - I*c_yx - c_yy
pair c1*c2 (pair2): c_xx - c_yy + I*(c_xy + c_yx)

Note: mapping to standard parameters t, δ may require factoring conventions:
For example, a kinetic term -t(c1d*c2 + c2d*c1) has coefficient -t for c1d*c2 here.
